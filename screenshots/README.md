# Product gallery assets

This directory contains responsive 900 px and 1600 px WebP captures for authentication, Course Studio, structured authoring, the learner player, and creator review. Light and dark variants are selected automatically by the [product tour](../docs/product-tour.md) where both themes are available.

All visible records are synthetic. Future assets must not include real emails, licensed course content, learner identifiers, submissions, or private URLs.
